## 3️⃣ 콘텐츠 등급(IARC) 체크 ★중요★

설문에서 다음 항목에 주의:

- **"도박과 유사한 요소"** 관련: 우리는 깨기권(매점/광고보상)으로 **확률적 상품 지급** → "가상 도박(Simulated gambling)" 계열로 분류될 수 있음. 솔직하게 체크하면 **12세+** 등급이 나올 가능성이 높음
- 가상화폐 현금 전환(환전성): 없음 → "결과를 현금으로 환전할 수 없음" 명시 가능
- 폭력: 없음 → 낮은 위험

> ⚠️ 등급을 역으로 속이면(예: 돈이 안 나간다고 도박류 아니라고 거짓 답변) 등급 취소나 앱 삭제가 있을 수 있어요. 솔직 입력 필수.

## 4️⃣ 등록 순서 (아빠 계정 콘솔에서)

1. 저장소 클론 → `npm ci` → `npm run build` (+ `npm start`로 서버 켜기)
2. `capacitor.config.ts`의 `server.url`을 배포 주소로 설정한 뒤 → `npm run cap:sync`
3. `npm run cap:open` → Android Studio에서 **Build > Generate Signed Bundle (AAB)**
   - 새 서명키 생성, 키스토어 파일/비밀번호는 안전하게 보관 (절대 git 커밋 금지)
   - 또는 Google Play App Signing 권장 (구글이 서명 관리)
4. 콘솔에서 앱 만들기 → **남부 테스트(Internal testing)** 트랙 → AAB 업로드 → 테스터 이메일(아빠와 본인) 추가
5. 다운/설치 확인 후 **프로덕션으로 승격** — 심사 며칠~2주. 도박 유사 판정 질문이 올 수 있으니 콘텐츠 사유서를 미리 준비해 둬요.

## 5️⃣ AdMob 이어가기
- AdMob 콘솔에 **앱 추가(플레이 등록과 연동)** → 앱-광고단위 연결 확인
- 광고단위 "서버 측 검증(SSV)"에 `https://(도메인)/api/ads/ssv` 입력 → `.env`에 `NEXT_PUBLIC_ADS_SSV_ACTIVE=1`
